# Components

Every component is exported from `orlune`. Each takes plain data. Anything derived (shares, totals, intervals) is computed inside the component, and verification state comes only from `verifyRecord`. Pass `className` to any of them.

Generated by `npm run docs` from the types in `src/`. Do not edit by hand.

## ControlChart

A control chart for a failure rate. It draws the centre line and the 1, 2 and 3 sigma limits for each point's own sample size, and marks points that break the standard run rules. A signal means "look closer", and the wording says so: it never claims something is broken, and a quiet chart never claims it is safe.

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `data` | `SpcPoint[]` | yes |  |
| `baseline` | `number \| undefined` | no | Points used to set the centre line. Defaults to all of them. |
| `markers` | `{ at: number; label: string; }[] \| undefined` | no | Vertical markers, for example a model release. `at` is a point index. |
| `height` | `number \| undefined` | no |  |

Install: `npx shadcn@latest add falnor-io/orlune/control-chart`

## ApprovalQueue

A review queue where an approval is bound to the exact plan. The plan is hashed, every decision records the hash it was made on, and a decision on an older version stops counting the moment the plan changes. Buttons say what will happen, the page says whether it can be undone and what evidence was checked, a second approval must come from a different person, and anything not decided in time expires instead of going through.

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `items` | `QueueItem[]` | yes |  |
| `reviewer` | `string` | yes | Who is looking. They cannot decide their own requests or decide twice. |
| `now` | `string \| Date \| undefined` | no |  |
| `blind` | `boolean \| undefined` | no | Hide other reviewers' decisions until this reviewer has decided, so a second approval is a... |
| `onDecide` | `((id: string, decision: DecisionKind, planHash: string) => void) \| undefined` | no |  |
| `defaultSelected` | `string \| undefined` | no |  |

Install: `npx shadcn@latest add falnor-io/orlune/approval-queue`
