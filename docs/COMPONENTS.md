# Components

Every component is exported from `orlune`. Each takes plain data. Anything derived (shares, totals, intervals) is computed inside the component, and verification state comes only from `verifyRecord`. Pass `className` to any of them.

Generated by `npm run docs` from the types in `src/`. Do not edit by hand.
