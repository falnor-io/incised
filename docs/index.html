References

What the advanced components were built against. Full notes, including what was not done, are in docs/REFERENCES.md.

  • Datadog, Trace View Flame graph with ruler and minimap, share of time by service, detail panel under the trace.
  • speedscope Dense flame chart, overview strip with a movable window.
  • Jaeger UI Critical path highlighting, timeline minimap, JSON view.
  • GitHub commit diff File tree with counts, hunk headers, line-number gutters, folded context.
  • React Flow Dotted pannable canvas, handles, minimap, controls, edge labels.
  • shadcn/ui AI Elements, Trace The existing Trace is a flat list of text lines. incised adds timing, structure and verification.
  • Kibo UI Lists Gantt and Contribution Graph components, the category for two incised components.
  • visx Low-level SVG chart primitives. incised draws SVG directly.
  • Agent approval UI patterns Bind approval to the exact plan, name the action, say whether it can be undone, show expired states.
