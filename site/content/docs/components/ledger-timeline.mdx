Signed events. Incident, re-test and remedy stand out.

## Installation

```bash
npx shadcn@latest add @orlune/ledger-timeline
```

Or import it from the package: `import { LedgerTimeline } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<LedgerTimeline events={good?.events} />
```
