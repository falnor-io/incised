<ComponentPreview name="Funnel" />

Share kept at each step is computed.

## Installation

```bash
npx shadcn@latest add falnor-io/orlune/funnel
```

Or import it from the package: `import { Funnel } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<Funnel title="How many make it through" unit="deals" steps={[{ label: 'Signed', value: 40 }, { label: 'Set up', value: 31 }, { label: 'Kickoff held', value: 22 }]} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `unit` | `string` | yes |  |
| `steps` | `{ label: string; value: number; }[]` | yes |  |

Pass `className` to add your own class.
