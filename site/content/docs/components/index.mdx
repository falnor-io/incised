## Complex

<Cards>
  <Card title="Chain graph" href="/docs/components/chain-graph">The ledger as linked hash blocks, showing exactly where a chain breaks.</Card>
  <Card title="Receipt card" href="/docs/components/receipt-card">A printable signed receipt for one action.</Card>
  <Card title="Trace explorer" href="/docs/components/trace-explorer">Flame graph, waterfall and span list on one axis, with minimap, zoom, search, critical path, a kind legend with share of time, and a detail panel.</Card>
  <Card title="Diff viewer" href="/docs/components/diff-viewer">Review-grade diff: file list, hunk headers, line numbers, folded context, changed words marked, split or unified, reviewer comments.</Card>
  <Card title="Flow canvas" href="/docs/components/flow-canvas">A pannable, zoomable flow diagram with swimlanes by owner, orthogonal edges, a minimap, controls and a step inspector.</Card>
  <Card title="Data grid" href="/docs/components/data-grid">A virtualized grid: multi-sort, per-column filters, resize, pinned column, range select, CSV export, keyboard control.</Card>
  <Card title="Control chart" href="/docs/components/control-chart">A p-chart for a failure rate with per-point 3-sigma limits and the Western Electric run rules.</Card>
  <Card title="Sankey" href="/docs/components/sankey">Where cases go, sized by volume, with cases that vanished at a node called out.</Card>
  <Card title="Approval queue" href="/docs/components/approval-queue">A review queue where approval is bound to the exact plan by hash, edits make approvals stale, two approvers must differ, and undecided requests expire.</Card>
  <Card title="Deadline gantt" href="/docs/components/deadline-gantt">Every deadline clock on one axis: met, running, overdue and remedied, worked out from the dates.</Card>
  <Card title="Activity heatmap" href="/docs/components/activity-heatmap">A calendar of activity with breach days marked and the longest run without a breach computed.</Card>
  <Card title="Eval matrix" href="/docs/components/eval-matrix">Cases by runs with exact intervals and a paired McNemar comparison of any two runs.</Card>
  <Card title="Fleet board" href="/docs/components/fleet-board">Sortable, filterable board of deployments with the tightest deadline computed.</Card>
</Cards>

## Judgement

<Cards>
  <Card title="Autonomy gate" href="/docs/components/autonomy-gate">When an agent has earned more autonomy: agreement with a person, an exact interval widened for repeated looks, and your rule. It says eligible, never promoted.</Card>
  <Card title="Evidence table" href="/docs/components/evidence-table">Each extracted value with the places it was read from. Coverage and conflicts between sources are counted, and there is no confidence score.</Card>
  <Card title="Plan vs actual" href="/docs/components/plan-vs-actual">What the agent said it would do next to what it did: skipped, failed, blocked, out of order and unplanned steps, found by comparing the lists.</Card>
  <Card title="Approval chain" href="/docs/components/approval-chain">Who has to approve, in order, and who is being waited on. Each step has a time limit, and a decision from the wrong person does not count and says why.</Card>
  <Card title="Handoff packet" href="/docs/components/handoff-packet">What an agent hands a person when it stops. The packet is checked: complete only when a person could act without asking the agent anything.</Card>
  <Card title="Permission grant" href="/docs/components/permission-grant">What an agent is allowed to do, how much of each allowance is left and when it ends. Status comes from the grant, the clock and what has been used.</Card>
  <Card title="Budget meter" href="/docs/components/budget-meter">Spend against a limit for a period, with a marker for how much of the period has gone and a straight-line projection you can check by hand.</Card>
</Cards>

## Workspace

<Cards>
  <Card title="Run inspector" href="/docs/components/run-inspector">One agent run in four views, with the four questions people ask of a run answered first: did it finish, did it follow the plan, were the tool calls sound, is every value sourced.</Card>
  <Card title="Approval workspace" href="/docs/components/approval-workspace">The approval queue with, for the request you are looking at, who has to approve, where each value came from and what the agent handed over.</Card>
  <Card title="Autonomy board" href="/docs/components/autonomy-board">Every agent in one list: its tier, whether it has earned a higher one, and what its grants and budget need. Each row is worked out from that agent's own cases, grants and budget.</Card>
</Cards>
