What the agent may do. The email grant is over its limit, the bank-update grant ends tonight, and the revoked wire grant is shown last, so nothing relies on the agent describing its own access.

## Installation

```bash
npx shadcn@latest add falnor-io/orlune/permission-grant
```

Or import it from the package: `import { PermissionGrant } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<PermissionGrant title="Invoice agent, permissions" grants={grantRows} now={NOW_ISO} />
```

## Props

| Prop | Type | Required | Notes |

| `title` | `string` | yes |  |
