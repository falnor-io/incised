What the agent may do. The email grant is over its limit. The bank-update grant ends tonight and acts for raj, who cannot update bank details himself, so the agent cannot either. The read grant has not been used in 50 days, and the revoked wire grant is last.

## Installation

```bash
npx shadcn@latest add @orlune/permission-grant
```

Or import it from the package: `import { PermissionGrant } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<PermissionGrant title="Invoice agent, permissions" grants={grantRows} now={NOW_ISO} userScopes={userScopes} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `grants` | `Grant[]` | yes |  |
| `now` | `string \| undefined` | no | Fixed clock for the verdicts. Defaults to the current time. |
| `userScopes` | `Record<string, string[]> \| undefined` | no | What each person may do. With it, a delegated grant is checked against the person it acts for. |
| `dormantDays` | `number \| undefined` | no |  |
| `requireOwner` | `boolean \| undefined` | no |  |

Pass `className` to add your own class.
