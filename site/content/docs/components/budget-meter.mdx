<ComponentPreview name="BudgetMeter" />

Spend against a limit. The marker is how much of the month has gone. Used so far is ahead of it, so at the recent rate the limit is reached before the month ends.

## Installation

```bash
npx shadcn@latest add @orlune/budget-meter
```

Or import it from the package: `import { BudgetMeter } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<BudgetMeter title="Model and tool spend, June" limit={1500} used={860} unit="USD" periodStart="2026-06-01T00:00:00Z" periodEnd="2026-07-01T00:00:00Z" samples={budgetSamples} now="2026-06-10T00:00:00Z" />
```
