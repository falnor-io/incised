<ComponentPreview name="FlowCanvas" />

Pan, zoom, minimap, swimlanes by owner, and click a step to trace what feeds it.

## Installation

```bash
npx shadcn@latest add @orlune/flow-canvas
```

Or import it from the package: `import { FlowCanvas } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<FlowCanvas title="Payment approval" nodes={flowNodes as never} edges={flowEdges as never} height={500} defaultSelected="limit" />
```

| Prop | Type | Required | Notes |

| `param` | `string \| undefined` | no |  |
