Review-grade diff: file list, hunks, line numbers, folded context, changed words, reviewer comments.

## Installation

```bash
npx shadcn@latest add @orlune/diff-viewer
```

Or import it from the package: `import { DiffViewer } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<DiffViewer title="Approval policy and prompt, v3 to v4" files={diffFiles} comments={diffComments} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `files` | `DiffFile[]` | yes |  |
| `comments` | `DiffComment[] \| undefined` | no |  |
| `context` | `number \| undefined` | no |  |
| `defaultMode` | `"split" \| "unified" \| undefined` | no |  |

Pass `className` to add your own class.
