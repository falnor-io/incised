Review-grade diff: file list, hunks, line numbers, folded context, changed words, reviewer comments.

## Installation

```bash
npx shadcn@latest add @orlune/diff-viewer
```

Or import it from the package: `import { DiffViewer } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<DiffViewer title="Approval policy and prompt, v3 to v4" files={diffFiles} comments={diffComments} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `files` | `DiffFile[]` | yes |  |
| `comments` | `DiffComment[] \| undefined` | no |  |
| `context` | `number \| undefined` | no |  |
| `defaultMode` | `"split" \| "unified" \| undefined` | no |  |
| `order` | `"given" \| "salience" \| undefined` | no | `salience` lists the files with the most real change first, so a reviewer starts where it matters. Moved code does not count. |
| `onDecideHunk` | `((path: string, hunk: number, decision: HunkDecision, digest: string) => void) \| undefined` | no | Adds accept and reject on each hunk. Each decision is tied to a digest of the file, so it stops counting once the file changes. |
| `onView` | `((path: string, viewed: boolean, digest: string) => void) \| undefined` | no | Called when a file is marked viewed or not, with the digest of what was viewed. |

Pass `className` to add your own class.
