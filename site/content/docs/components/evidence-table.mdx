<ComponentPreview name="EvidenceTable" />

Each value with where it was read from. Coverage and conflicts are counted from the sources, and there is no confidence score.

## Installation

```bash
npx shadcn@latest add @orlune/evidence-table
```

Or import it from the package: `import { EvidenceTable } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<EvidenceTable title="Invoice INV-2291, extracted values" rows={evidenceRows} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `rows` | `EvidenceRow[]` | yes |  |
| `documents` | `Record<string, string> \| undefined` | no | Your document text by id. A source with a `docId` has its excerpt looked up in it, and one that is not there is flagged. |
| `available` | `AvailableValue[] \| undefined` | no | What the source documents contain, so values the agent left out can be named. |

Pass `className` to add your own class.
