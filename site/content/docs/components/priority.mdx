Impact against effort. Labelled as a judgement.

## Installation

```bash
npx shadcn@latest add falnor-io/orlune/priority
```

Or import it from the package: `import { Priority } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<Priority title="Where to start" items={[
  { label: 'Handoff to operations', impact: 'high', effort: 'low' },
  { label: 'Project set up', impact: 'high', effort: 'high' },
  { label: 'Kickoff booked', impact: 'low', effort: 'low' },
]} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `items` | `{ label: string; impact: "high" \| "low"; effort: "high" \| "low"; }[]` | yes |  |

Pass `className` to add your own class.
