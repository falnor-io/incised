<ComponentPreview name="Sankey" />

Where cases go, sized by volume. A node that loses cases says so.

## Installation

```bash
npx shadcn@latest add @orlune/sankey
```

Or import it from the package: `import { Sankey } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<Sankey title="Where 1,900 invoices went" nodes={sankeyNodes} links={sankeyLinks} unit="invoices" />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `nodes` | `(SankeyNode & { tone?: "good" \| "warn" \| "bad"; })[]` | yes |  |
| `links` | `SankeyLink[]` | yes |  |
| `unit` | `string \| undefined` | no |  |
| `height` | `number \| undefined` | no |  |

Pass `className` to add your own class.
