Escalation counts as a correct outcome.

## Installation

```bash
npx shadcn@latest add @orlune/approval-gate
```

Or import it from the package: `import { ApprovalGate } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<ApprovalGate action="Release payment over the approval limit" approver="Controller" state="escalated" note="The agent held the payment and asked a person." />
```
