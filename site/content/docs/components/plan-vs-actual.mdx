<ComponentPreview name="PlanVsActual" />

What the agent planned next to what it did. Skipped, failed, blocked, late and unplanned steps are found by comparing the two lists.

## Installation

```bash
npx shadcn@latest add @orlune/plan-vs-actual
```

Or import it from the package: `import { PlanVsActual } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<PlanVsActual title="Invoice run, plan against actual" plan={planSteps} actual={actualSteps} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `plan` | `PlanStep[]` | yes |  |
| `actual` | `ActualStep[]` | yes |  |

Pass `className` to add your own class.
