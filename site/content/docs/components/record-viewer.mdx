<ComponentPreview name="RecordViewer" />

One record on one page: the verdict, each guarantee against what the verifier found, the signed events and the hash chain. It can save the verifier's output.

## Installation

```bash
npx shadcn@latest add @orlune/record-viewer
```

Or import it from the package: `import { RecordViewer } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<RecordViewer title="Engagement record" result={good} manifest={record.manifest} />
```

## Props

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `result` | `VerifyResult \| null` | yes | What `verifyRecord` returned. Without one the viewer says "Not verified". |
| `manifest` | `Manifest \| null \| undefined` | no |  |

Pass `className` to add your own class.
