The queue with, for the request you are looking at, who has to approve, where the values came from and what the agent handed over. A tab appears only when the request has that part.

## Installation

```bash
npx shadcn@latest add @orlune/approval-workspace
```

Or import it from the package: `import { ApprovalWorkspace } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
{queue && <ApprovalWorkspace title="Approvals waiting" items={queue.map((q) => ({ queue: q, ...(workspaceExtras[q.id] ?? {}) }))} reviewer="raj" now={NOW_ISO} />}
```
