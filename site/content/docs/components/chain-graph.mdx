Hash chain. The break shows where trust stops.

## Installation

```bash
npx shadcn@latest add falnor-io/orlune/chain-graph
```

Or import it from the package: `import { ChainGraph } from 'orlune'`.

## Example

The data below is the data in the preview above.

```tsx
<ChainGraph events={bad?.events} />
```

| Prop | Type | Required | Notes |
| --- | --- | --- | --- |
