Orlune is a set of React components for the part of an agent product that comes after the chat: the review, the approval, the record and the proof.

It follows one rule: **the model fills in data, the interface computes everything derived, and verification state never comes from a model.**

- A funnel works out the share kept at each step. No schema contains that figure, so a model cannot make one up.
- `VerifyStatus` renders only a result from `verifyRecord`. With no result it says "Not verified", never a pass.
- An approval is bound to a hash of the exact plan. Edit the plan and earlier approvals go stale.
- Anything that fails its schema renders nothing.

## Install one

```bash
npx shadcn@latest add @orlune/approval-queue
```

Add the registry first, once per project. See [Installation](/docs/installation).

The files are copied into your project, so you own and can edit them.

To try a component first, open the [playground](/playground): change its props, switch theme and width, and copy the code.

## Where it fits

Orlune does not draw chat. Use your chat library for messages and prompts, and Orlune for the screens a person opens to decide, review or prove something. See [Why Orlune](/docs/principles).
